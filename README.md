# Facial Attendance System

A desktop application that marks attendance automatically by recognising faces from a webcam or IP camera. Faces are detected with OpenCV, turned into 512-dimensional embeddings by an **ArcFace ResNet-100** model running on **Intel OpenVINO**, and matched against registered students by cosine similarity. A **PyQt5** interface covers the whole workflow: registering students, training, live recognition and viewing or exporting the attendance log.

The repository also contains an earlier version of the system (Tkinter + LBPH) in `Face recognition first/`, kept for reference.

## Features

- **Live recognition** from the default webcam, an external USB camera, or an **IP/RTSP stream** (for example a phone running an IP-camera app).
- **Face registration** inside the app: enter a name, choose how many images to capture (10–200, default 50), and the app saves cropped face images automatically.
- **One-click training**: encodes every registered face with ArcFace and saves the embeddings to `model/model.pkl`.
- **Automatic attendance logging** to CSV, at most **once per person per day**.
- **Attendance log viewer** with date filtering, refresh and CSV export.
- **Settings tab** to choose the model, embeddings file and log location; settings persist between runs.
- **Standalone executable** packaging with PyInstaller (`installerscript.py`).

## How it works

```
Camera frame ─► Haar cascade face detection (OpenCV)
             ─► crop + resize face to the model's input size
             ─► ArcFace ResNet-100 on OpenVINO (CPU)  ─► 512-d embedding
             ─► cosine similarity vs. registered embeddings
             ─► best match above 0.5  ─► name drawn on screen + attendance row written
```

Training does not fine-tune any network. It runs each registered face image through the pretrained ArcFace model and stores the L2-normalised embeddings with their names. Adding a new person therefore only means capturing images and re-running training, which takes seconds.

## Installation

Python 3.8 or newer is recommended.

```bash
git clone https://github.com/garvitp06/Eyantra-lab-face-recognition.git
cd Eyantra-lab-face-recognition
pip install -r requirements.txt
```

### Get the ArcFace model

The OpenVINO model files are not stored in the repository because of their size.

1. Download `arcfaceresnet100-8.onnx` from the ONNX Model Zoo (ArcFace).
2. Convert it to OpenVINO IR format:
   ```bash
   ovc arcfaceresnet100-8.onnx      # OpenVINO 2023.1 and newer
   # or, on older versions:
   mo --input_model arcfaceresnet100-8.onnx
   ```
3. Put the resulting `arcfaceresnet100-8.xml` and `arcfaceresnet100-8.bin` in an `openvino_model/` folder in the project root.

You can also point the app at a different location from the **Settings** tab.

## Usage

```bash
python frontend.py
```

1. **Registration tab:** select the dataset folder (`dataset/`), enter the student's name, set the number of images and click **Register Face**. Look at the camera and move your head slightly while images are captured.
2. **Training tab:** select the dataset folder, the OpenVINO `.xml` model and an output file (for example `model/model.pkl`), then click **Train Model**.
3. **Recognition tab:** choose a **Camera Source** if you are not using the default webcam, then click **Start Recognition**. Recognised students are labelled on screen and logged.
4. **Attendance Log tab:** filter by date, refresh, or export the log to CSV.

### Using a phone or IP camera

Choose **Camera Source → IP Camera/RTSP** and enter the stream URL, for example:

```
rtsp://192.168.1.10:8080/h264.sdp
```

The phone and the computer must be on the same network.

### Command-line alternative

```bash
python training_1.py    # prompts for dataset folder, output file and names; captures 100 images each
python main_file_1.py   # live recognition in an OpenCV window; press q to quit
```

`main_file_1.py` expects the model at `converted_ir/new/arcfaceresnet100-8.xml` and writes to `attendance/attendance.csv`.

### Build an executable

```bash
python installerscript.py frontend.py --onefile --output dist
```

Copy the `openvino_model/` and `model/` folders next to the generated executable.

## Version 1 (`Face recognition first/`)

The first version of the project uses a different pipeline:

- **Tkinter** GUI with subject-wise attendance sessions.
- Haar cascade detection with OpenCV's **LBPH** face recognizer (`TrainingImageLabel/Trainner.yml`).
- Per-subject attendance CSVs with enrollment number, name, date and time, a manual attendance option, and an admin panel for viewing student details.
- Optional MySQL storage through `pymysql`.

Run it with `python AMS_Run.py` from inside that folder. It additionally needs `opencv-contrib-python` (for `cv2.face`), `pillow`, `pandas` and `pymysql`.

The current version replaces LBPH with deep ArcFace embeddings, which are much more robust to lighting, pose and expression changes, and need only a few dozen images per person.

## Configuration notes

| Setting | Where | Default |
|---|---|---|
| Recognition threshold (cosine similarity) | `main_file_1.py`, `recognize_faces_batch` | 0.5 |
| Inference device | `frontend.py`, `compile_model(..., device_name=...)` | `"CPU"` (can be `"GPU"` on Intel graphics) |
| Images captured per person | Registration tab spinner | 50 |
| Attendance log path | Settings tab | `attendance/attendance.csv` |

A higher threshold reduces false matches but may miss students in poor lighting.

## Known limitations

- `training.py`, `training_1.py` and `main file.py` contain hard-coded Windows paths (`D:/Project/...`, `F:/Project/...`); edit them before use, or use `frontend.py`, which uses paths relative to the project folder.
- The match confidence shown in the GUI is a placeholder (1.0); the similarity score is not yet passed through from `recognize_faces_batch`.
- Haar cascades are fast but can miss faces at strong angles or in low light.
- There is no liveness check, so a printed photo of a registered student may be recognised.
- `converter.py` is a template: its output path must be set to a `.onnx` file name, and it needs `torch`, which is not listed in `requirements.txt`.
- `frontend.py` sets the window icon from `icon.png`, which is not included. The app runs without it.

## Privacy

Face images, `model/model.pkl` (face embeddings) and attendance CSVs are personal data. Before making the repository public, keep them out of Git by adding these lines to `.gitignore`:

```
dataset/
model/*.pkl
attendance/*.csv
attendance.csv
Face recognition first/Attendance/
Face recognition first/StudentDetails/
Face recognition first/TrainingImage/
Face recognition first/TrainingImageLabel/
facial_attendance_settings.pkl
.idea/
*.rar
```

Only register people who have agreed to it.
